# منصة سي مهيب العقارية (Kreya App) 🏠🔥

النظام الذكي الأول في تونس لإدارة العقارات، عقود الكراء، ومتابعة فواتير الاستهلاك (STEG / SONEDE) مع تكامل مباشر مع الواتساب والدفع الإلكتروني.

## 🔗 رابط الموقع المباشر
يمكنك تجربة المنصة حية الآن على الإنترنت عبر الرابط التالي:
[https://souissimouhib19-spec.github.io/kreya-app/](https://souissimouhib19-spec.github.io/kreya-app/)

---

## 🚀 مميزات المنصة:
- **دعم الأدوار المتعددة:** واجهات مخصصة لكل من (الطالب/المكتري، المالك، والإدارة العامة).
- **التواصل الفوري (WhatsApp):** توجيه الطلبات وعقود الكراء مباشرة إلى رقم الإدارة (`+216 29 461 304`).
- **توليد العقود:** صنع عقود الكراء التونسية ببيانات حية ومباشرة.
- **التنسيق المالي:** جاهز لدمج بوابات الدفع التونسية (Flouci / D17).

---

## 🛠️ التقنيات المستخدمة:
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Hosting:** GitHub Pages
- **Backend (قيد التطوير):** Node.js & Express
